# 问卷星自动填写工具 · 使用手册

本手册针对 `wjx-automation/python/` 下的 Python 版工具,按步骤说明怎么安装、解析问卷、生成比例、批量填写。

## 一、环境准备

### 1. 安装 Python

在 PyCharm 中新建项目时选择 Python 3.9+ 解释器即可;也可以自己装 Python 后运行:

```bash
python --version
```

能输出版本号就说明 Python 环境正常。

### 2. 安装 playwright(国内用清华镜像)

在 PyCharm 的 Terminal 中进入本目录并安装依赖:

```bash
cd "C:\Users\江建锋\Documents\ChatGPT\New project\wjx-automation\python"
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

如果本机没有 Chrome/Edge,再装一个浏览器内核(一般不需要,脚本优先用系统浏览器):

```bash
PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright/ playwright install chromium
```

## 二、配置 DeepSeek API Key(可选,用于 AI 生成比例)

把 key 写进本目录的 `.env` 文件(已被 git 忽略,不会提交):

```bash
echo "DEEPSEEK_API_KEY=sk-你的key" > .env
```

或者用环境变量:

```bash
export DEEPSEEK_API_KEY="sk-你的key"
```

> 注意:key 如果在对话/群里发过,建议去 DeepSeek 后台重新生成一个再使用。

## 三、解析问卷并生成 config(推荐带 --ai)

一条命令完成:打开问卷 → 识别题目 → 调用 DeepSeek 生成建议比例 → 写入 config.json(旧配置自动备份为 config.backup.json):

```bash
python parse_survey.py --url "https://v.wjx.cn/vm/Y3drsEm.aspx" --out config.json --ai
```

不想要 AI 比例,用默认等权重:

```bash
python parse_survey.py --url "https://v.wjx.cn/vm/Y3drsEm.aspx" --out config.json
```

第三方中转模型可指定模型名:

```bash
python parse_survey.py --url "问卷链接" --out config.json --ai --model "你的模型名"
```

解析完成后,检查一下 config.json:

```bash
cat config.json
```

## 四、手动调整比例(可选)

打开 config.json,找到对应题目的 `weights`,直接改数字即可。单选题同一题加起来建议等于 100;多选题每个数字表示"该选项被选中的概率"(0-100)。

```json
{
  "match": "你的性别",
  "weights": { "男": 48, "女": 52 }
}
```

## 五、开始填写

### 1. 先有头模式试一次(能看到浏览器操作)

```bash
python fill_wjx.py --config config.json --headed
```

### 2. 确认没问题后,无头批量刷

```bash
python fill_wjx.py --config config.json --headless --count 100
```

`--count` 就是要提交的份数,默认 1。刷完脚本会自动输出每题的实际分布统计,方便核对比例。

### 3. 常用参数

```bash
# 调整操作间隔(毫秒),频率高怕被风控就调大
python fill_wjx.py --config config.json --headed --delay 1500-3000

# 固定随机种子,结果可复现
python fill_wjx.py --config config.json --seed 42

# 强制输出分布统计
python fill_wjx.py --config config.json --count 100 --stats

# 出问题时打印识别到的题目结构
python fill_wjx.py --config config.json --debug
```

## 六、常见问题

### ModuleNotFoundError: No module named 'playwright'

解释器不对或没装依赖。在 PyCharm 里检查 Settings → Project → Python Interpreter 是否选了装过 playwright 的那个环境,或者重新执行:

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 提示"配置文件不存在"

`--config` 后面的路径不对。先确认当前目录:

```bash
pwd
ls config.json
```

### 提示"未能识别到问卷题目"

问卷已结束、需要登录,或页面模板结构差异。用 `--debug` 查看,或把问卷链接和报错发回来。

### 提交后提示"未检测到提交成功"

必填题没填上或页面出现验证码。查看 screenshots 目录的失败截图;有验证码时改用 `--headed` 手动完成。

### 换新问卷怎么操作?

只需两步,不用改代码:

```bash
python parse_survey.py --url "新问卷链接" --out config.json --ai
python fill_wjx.py --config config.json --headed
```

## 七、使用须知

本工具仅适用于填写自己创建或已获授权的问卷。请勿用于伪造调查数据、刷票或干扰他人问卷;平台有反作弊机制(验证码、IP 频次、答题时长等),滥用可能导致账号或问卷被处理,后果自负。
