# 问卷星自动填写工具 · 使用手册

本手册针对 `wjx-automation/python/` 下的 Python 版工具,按步骤说明怎么安装、解析问卷、生成比例、批量填写。

## 一、环境准备

### 1. 安装 Python

在 PyCharm 中新建项目时选择 Python 3.9+ 解释器即可;也可以自己装 Python 后运行:

```bash
python --version
```

能输出版本号就说明 Python 环境正常。

### 2. 安装 playwright(国内用清华镜像)

在 PyCharm 的 Terminal 中进入本目录并安装依赖:

```bash
cd "C:\Users\江建锋\Documents\ChatGPT\New project\wjx-automation\python"
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

如果本机没有 Chrome/Edge,再装一个浏览器内核(一般不需要,脚本优先用系统浏览器):

```bash
PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright/ playwright install chromium
```

## 二、配置 DeepSeek API Key(可选,用于 AI 生成比例)

把 key 写进本目录的 `.env` 文件(已被 git 忽略,不会提交):

```bash
echo "DEEPSEEK_API_KEY=sk-你的key" > .env
```

或者用环境变量:

```bash
export DEEPSEEK_API_KEY="sk-你的key"
```

> 注意:key 如果在对话/群里发过,建议去 DeepSeek 后台重新生成一个再使用。

## 三、解析问卷并生成 config(推荐带 --ai)

一条命令完成:打开问卷 → 识别题目 → 调用 DeepSeek 生成建议比例 → 写入 config.json(旧配置自动备份为 config.backup.json):

```bash
python parse_survey.py --url "https://v.wjx.cn/vm/Y3drsEm.aspx" --out config.json --ai
```

不想要 AI 比例,用默认等权重:

```bash
python parse_survey.py --url "https://v.wjx.cn/vm/Y3drsEm.aspx" --out config.json
```

第三方中转模型可指定模型名:

```bash
python parse_survey.py --url "问卷链接" --out config.json --ai --model "你的模型名"
```

解析完成后,检查一下 config.json:

```bash
cat config.json
```

## 四、手动调整比例(可选)

打开 config.json,找到对应题目的 `weights`,直接改数字即可。单选题同一题加起来建议等于 100;多选题每个数字表示"该选项被选中的概率"(0-100)。

```json
{
  "match": "你的性别",
  "weights": { "男": 48, "女": 52 }
}
```

## 五、开始填写

### 1. 先有头模式试一次(能看到浏览器操作)

```bash
python fill_wjx.py --config config.json --headed
```

### 2. 确认没问题后,无头批量刷

```bash
python fill_wjx.py --config config.json --headless --count 100
```

`--count` 就是要提交的份数,默认 1。刷完脚本会自动输出每题的实际分布统计,方便核对比例。

### 3. 常用参数

```bash
# 调整操作间隔(毫秒),频率高怕被风控就调大
python fill_wjx.py --config config.json --headed --delay 1500-3000

# 固定随机种子,结果可复现
python fill_wjx.py --config config.json --seed 42

# 强制输出分布统计
python fill_wjx.py --config config.json --count 100 --stats

# 出问题时打印识别到的题目结构
python fill_wjx.py --config config.json --debug

# 查看每题填写明细和代理明细(默认只输出每次提交的成功/失败结果)
python fill_wjx.py --config config.json --verbose
```

> 默认运行时输出已精简:只显示每次提交的开始、成功/失败结果和耗时,以及必要的警告。多线程下日志带 `[线程N]` 前缀方便区分。

## 六、代理 IP 池(可选,让每次提交来自不同 IP)

脚本支持代理 IP 池:每次提交会新建独立浏览器会话,并从池中轮换一个代理,保证出口 IP 不同,降低同 IP 高频提交被风控的概率。

### 1. 免费代理池(零成本,推荐先试用)

脚本附带免费代理更新工具,自动从多个公开源抓取 → 去重 → 并发验证(必须能访问国内网站)→ 写入 `proxies.txt`:

```bash
python update_proxies.py
```

`config.json` 已默认配置 `"proxy_file": "proxies.txt"`,刷新完直接运行填写脚本即可:

```bash
python fill_wjx.py --config config.json --count 20
```

运行日志会显示每次使用的代理,例如:

```text
[信息] 代理模式: 代理池(共 139 个)
[线程0] 使用代理: http://101.66.194.210:8085
```

> 注意:免费代理可用率约 10%、存活时间只有几分钟到几小时,建议**每次批量提交前都先跑一遍 `update_proxies.py`**。
>
> 免费代理基本来自机房 IP,匿名性差,问卷星可能识别为代理并触发验证码;如频繁触发,建议改用付费代理(见下方方式三)。

### 2. 自备代理列表

代理格式:`http://user:pass@ip:port` 或 `socks5://ip:port`,三种写法任选:

```jsonc
// 方式 A:文本文件(每行一个,# 开头为注释),config.json 里:
"proxy_file": "proxies.txt"

// 方式 B:直接写在配置里
"proxy_list": ["http://user:pass@ip1:8080", "socks5://ip2:1080"]

// 方式 C:单个固定代理
"proxy": "http://user:pass@ip:8080"
```

### 3. 代理服务商 API(稳定,付费或试用)

填写代理商提供的提取/隧道 API,每次提交自动获取新 IP(如 IPIPGO、天启HTTP、光络云等,均有免费试用额度):

```jsonc
"proxy_api": "https://api.代理商.com/get?num=1&format=json"
```

### 4. 代理配置字段总览

| 字段 | 说明 |
| --- | --- |
| `proxy` | 单个固定代理,字符串或对象 |
| `proxy_list` | 代理池(内联数组) |
| `proxy_file` | 代理池(文件路径,每行一个) |
| `proxy_api` | 代理 API,每次动态提取新 IP |
| `proxy_verify` | 是否预验证连通性,默认 `true` |
| `proxy_verify_timeout` | 验证超时秒数,默认 8 |
| `proxy_retry` | 代理失效时自动换代理重试次数,默认 2 |

> 优先级:`proxy` > `proxy_list` > `proxy_file` > `proxy_api`,同时配置只取第一个生效。代理池数量建议 ≥ 提交份数,才能保证每次 IP 不同。

## 七、多线程并发加速(可选,count 较大时用)

默认单线程串行提交;开启多线程后同时开多个浏览器并行填写,速度成倍提升:

```bash
# 4 线程并发提交 20 份
python fill_wjx.py --config config.json --count 20 --threads 4
```

或在 `config.json` 里写 `"threads": 4`(默认 1,即串行)。

注意事项:

- 每个线程独立启动一个浏览器实例,内存占用约 300MB/线程,**建议 2~5 个线程**;
- 有头模式(`headless: false`)会同时弹出多个浏览器窗口;
- 并发提交 + 免费代理更容易触发验证码,风控变严时先降低线程数或调大 `delay_min_ms/delay_max_ms`;
- 代理池数量应 ≥ 并发线程数,否则多个线程会拿到重复 IP。

## 八、常见问题

### ModuleNotFoundError: No module named 'playwright'

解释器不对或没装依赖。在 PyCharm 里检查 Settings → Project → Python Interpreter 是否选了装过 playwright 的那个环境,或者重新执行:

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 提示"配置文件不存在"

`--config` 后面的路径不对。先确认当前目录:

```bash
pwd
ls config.json
```

### 提示"未能识别到问卷题目"

问卷已结束、需要登录,或页面模板结构差异。用 `--debug` 查看,或把问卷链接和报错发回来。

### 提交后提示"未检测到提交成功"

必填题没填上或页面出现验证码。查看 screenshots 目录的失败截图;有验证码时改用 `--headed` 手动完成。

### 换新问卷怎么操作?

只需两步,不用改代码:

```bash
python parse_survey.py --url "新问卷链接" --out config.json --ai
python fill_wjx.py --config config.json --headed
```

### 日志显示"直连(未启用代理)",代理没生效?

说明代理配置没被解析到。检查:`proxy_file` 指向的文件是否存在、格式是否为 `ip:port` 或 `http://ip:port`;或先跑 `python update_proxies.py` 生成 `proxies.txt`。

### 日志显示"代理池为空/全部失效"?

免费代理失效很快,重新运行 `python update_proxies.py` 刷新;若刷新后仍很少,可加 `--timeout 6 --verify-url https://www.baidu.com` 提高验证通过率(默认已用 HTTPS 验证,能过滤掉不支持 HTTPS 隧道的代理,必须保留 HTTPS 否则问卷星会打不开)。

### 使用代理后频繁出现验证码/提交失败?

免费代理多来自机房 IP,容易被问卷星风控识别。可尝试:降低 `--threads`、调大 `delay_min_ms/delay_max_ms`、更换 `proxies.txt`;仍不行建议换付费住宅代理(填 `proxy_api`)。

## 九、使用须知

本工具仅适用于填写自己创建或已获授权的问卷。请勿用于伪造调查数据、刷票或干扰他人问卷;平台有反作弊机制(验证码、IP 频次、答题时长等),滥用可能导致账号或问卷被处理,后果自负。
