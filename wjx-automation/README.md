# 问卷星自动填写脚本

基于 Playwright 的问卷星(www.wjx.cn)自动填写工具。打开问卷链接,按规则自动填写并提交,支持多次连续提交。

## 使用须知

本脚本只建议用于以下场景:

- 测试自己创建的问卷(检查题目、选项、必填逻辑是否正常);
- 批量录入已获授权允许自动填写的问卷。

请勿用于伪造调查数据、刷票、灌水或干扰他人问卷。问卷星平台有验证码、答题时长、IP 频次等反作弊机制,滥用可能导致账号或问卷被处理,后果自负。

## 环境要求

- Windows + 已安装的 Chrome 或 Edge(本机已检测到,无需下载浏览器内核);
- Node.js 18+。本仓库已适配 Codex 桌面版自带的 Node.js,直接运行 `run.ps1` 即可,无需安装任何依赖。

## 快速开始

1. 复制 `config.example.json` 为 `config.json`,填入问卷链接和答案规则。
2. 运行:

```powershell
powershell -ExecutionPolicy Bypass -File run.ps1 --config config.json
```

首次建议加 `--headed` 打开浏览器窗口观察效果:

```powershell
powershell -ExecutionPolicy Bypass -File run.ps1 --config config.json --headed
```

也可以直接用 Node 运行:

```powershell
node fill_wjx.js --config config.json
```

## 配置文件说明

| 字段 | 说明 | 默认值 |
| --- | --- | --- |
| `url` | 问卷链接(必填) | - |
| `count` | 连续提交次数 | 1 |
| `headless` | true=无头模式,false=显示浏览器窗口 | true |
| `delay_min_ms` / `delay_max_ms` | 每步操作间的随机间隔 | 300 / 1200 |
| `timeout_ms` | 等待提交成功的超时时间 | 30000 |
| `unmatched` | 未匹配到规则的题目怎么处理:`random` 随机填,`skip` 跳过 | random |
| `random_seed` | 随机种子,设置后结果可复现 | null |
| `screenshots_dir` | 每次提交后截图保存目录 | screenshots |
| `shots_success` | 提交成功后是否截图(默认 false,只在失败/未填时截图) | false |
| `rules` | 答案规则数组,见下 | [] |

### 答案规则 `rules`

每条规则用正则 `match` 匹配题目文字(不区分大小写),`value` 指定答案:

```json
{
  "rules": [
    { "match": "姓名", "value": "测试用户{n}" },
    { "match": "性别", "value": "女" },
    { "match": ".*爱好.*", "value": ["阅读", "运动"] },
    { "match": "城市", "value": "上海" },
    { "match": "满意度", "value": { "页面设计": 4, "操作便捷性": "满意" } },
    { "match": "建议", "value": "这是一份自动化测试建议。" }
  ]
}
```

`value` 的取值方式:

- 单选题 / 下拉题:选项文字、选项序号(从 1 开始)或 `"random"`;
- 多选题:选项数组,如 `["阅读", "运动"]`,或 `"random"` 随机选 1~3 项;
- 填空题:直接填文字,`{n}` 会被替换为当前提交次数;`"random"` 会按输入框类型生成邮箱/手机号/数字等;
- 填空题答案池:传字符串数组,多份提交时自动轮换,如 `["答案一", "答案二", "答案三"]`;
- 矩阵题(量表):`"random"` 或对象 `{ "行标题": 列序号或列文字 }`,例如 `{ "页面设计": 4, "响应速度": "满意" }`;
- 未写规则且 `unmatched` 为 `random` 时,所有题目随机填写。

`match` 支持任意正则,例如 `"建议|意见"`、`".*爱好.*"`、`"^第\\d+题"`。

### 按比例填写(`weights`)

批量刷多份时,可以用 `weights` 指定每个选项的占比,单选按比例分布,多选按每项选中率:

```json
{
  "rules": [
    { "match": "性别", "weights": { "男": 40, "女": 60 } },
    { "match": ".*爱好.*", "weights": { "阅读": 70, "运动": 50, "音乐": 30, "旅行": 20 } }
  ]
}
```

规则说明:

- **单选题 / 下拉题**:权重是相对占比,自动归一化,总和不必严格等于 100(建议写百分比);
- **多选题**:每个选项的权重表示"被选中的概率"(0-100,写 0-1 的小数也会自动换算成百分比),总和可以大于或小于 100;脚本保证每题至少选中一个选项;
- 选项按文字精确匹配,也可以写序号键 `"1": 30, "2": 70`;
- 刷完 N 份后,脚本会自动输出每题的实际分布统计,方便核对比例是否符合预期。

示例:刷 100 份、男女 4:6:

```powershell
node fill_wjx.js --config config.json --count 100
```

`--stats` 可以强制输出分布统计(默认 `count` 大于 1 时自动输出)。

## 支持与不支持的题型

支持:单选题、多选题、填空题、下拉题、矩阵单选题(量表)、评分星。

暂不支持:排序题、上传附件题、图片/视频选择等特殊题型。遇到这些题目脚本会打印"填写失败"并继续,不会阻塞其他题目。

## 命令行参数

```text
--config <file>   配置文件路径
--url <url>       问卷链接(覆盖配置文件)
--count <n>       提交次数
--headed          有头模式
--headless        无头模式(默认)
--delay <min-max> 操作间隔,如 500-1500
--timeout <ms>    提交等待超时
--seed <n>        随机种子
--shots <dir>     截图目录
--debug           输出识别到的题目结构
-h, --help        帮助
```

## 常见问题

**遇到验证码/滑块怎么办?**
脚本无法也不应绕过验证码。改用 `--headed` 模式,出现验证码时手动拖一下,脚本会继续等待提交成功。

**提示"未能识别到问卷题目"**
可能是问卷已结束、需要登录,或页面模板结构差异。用 `--debug` 查看识别结果,或把问卷截图发来我可以适配。

**提交后提示"未检测到提交成功"**
通常是必填题没填上。查看 `screenshots` 目录里的失败截图,确认是哪道题,再补充对应规则。

**多次提交被平台拦截?**
这是正常的反作弊行为。降低频率(调大 `delay`)、减少 `count`,并只用于合规场景。
